# 邮件功能清理验收

关联 Issue #12；实施方案见 [remove-email-plan.md](remove-email-plan.md)。验证环境仅为隔离数据库 `jt_idea_auth_test` 与 4184 的 `jt_idea_accounts_dev`。

## 已验证

- 删除邮件发送服务、邮件任务/模板、邮件配置及开发 MailHog 依赖。4184 通过启动包装器移除全部 `EMAIL*` 与 `USER_LIST*` 环境变量后启动成功。
- 实际检查 4184 个人设置：保留只读用户名、昵称、默认/自定义头像、四项站内通知、修改密码及原有个人账号删除入口；无邮箱、修改邮箱、邮件开关、Gravatar。头像相关中文译名已校正。
- 个人设置保存成功；通过真实 HTTP 验证管理员创建无邮箱成员、临时密码首次修改、密码登录、昵称/通知保存。
- 会话与成员 API 不再包含邮箱。旧邮件登录、邀请、注册、邮箱修改、Gravatar 和站点邮件取消链接请求返回 404。
- 隔离成员新增合成记录后，管理员站内通知实际送达，并在浏览器通知菜单中可见。历史站内通知保留。
- 存储测试覆盖旧通知偏好 `3→1`、`2→0`、无邮箱成员接收、停用成员不接收；新提交的邮件位 2/3 被拒绝。
- 模型测试覆盖旧 Gravatar 类型自动显示默认头像、自定义头像不变。Webhook 测试覆盖所有事件不输出邮箱，旧邮箱变量明确报错且不会发出 HTTP 请求，有效模板仍可发送。
- Go 全包短测试及 race 检查、前端 26 个测试套件 / 233 项测试、TypeScript、lint、前后端构建通过。

## 兼容与边界

历史数据库列、迁移、邮箱值和备份格式保留，以免损坏既有数据或升级兼容；它们不再参与登录、通知或头像。完整历史备份仍可能包含原始邮箱数据。邮件发送链路已删除，旧邮件环境变量无法重新开启。

邮件相关旧测试随被删除功能退役，非邮件业务测试保留；本次新增了站内通知、头像兼容及缺失 Webhook 变量的回归检查。旧 E2E 邮件注册脚本改为隔离容器中的账号初始化与密码登录，通过 Python AST、TypeScript、ESLint 和 Cucumber dry-run 检查（10 场景 / 46 步，未实际执行）；本轮没有构建 Linux 发布镜像并运行整套 Docker E2E。实际行为通过 4184 浏览器和 HTTP、隔离数据库测试验证。

当前未提交、未合并 main、未更新 4180 或云端。原工作区 UI 修改保留在同一待交付分支中。4184 中新增少量明确标记的合成验收账号/记录，原账号、记录、附件未删除。
