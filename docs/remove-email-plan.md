# 移除邮件功能

## 范围

本项目只供内部人员使用，身份由管理员创建的固定用户名和密码确定。个人设置不再包含邮箱、修改邮箱、邮件通知或依赖邮箱的 Gravatar；保留昵称、默认头像、自定义头像、修改密码和站内通知。

移除旧版邮件登录与验证码、公开注册及激活、邮件邀请、邮箱修改/验证、SMTP/Mailgun/AWS SES 发送实现及配置、邮件模板、退信任务和 UserList 邮件营销同步。依赖邮件取消链接的站点定时删除流程一并移除；现有管理员启停账号继续使用。已有密码登录之外的旧 OAuth 入口与邮件映射界面同属失效流程，随之清理。

用户会话、成员列表、审核数据及 Webhook 不再输出邮箱；Webhook 的 `*_email` 变量不再提供。旧模板中使用此变量的配置应改用已有 `*_id` 或 `*_name`。邮件服务的旧环境变量不会重新开启发送。

## 数据兼容

保留历史数据库迁移、用户邮箱列和已存数据，避免破坏既有账号/记录及升级回退；不再提供邮箱查询、修改或验证接口。新账号仍只依赖用户名与密码。历史头像类型 2 在读取时使用默认头像，类型 3 的自定义头像保留。历史通知值按站内通知位读取：3→1，2→0；新设置只允许 0/1。清理不修改既有记录、附件、用户或通知数据。

## 验证与交付

验证无邮件配置可启动；旧邮件路由不可用；会话和成员 API 无邮箱；昵称/头像/站内通知保存和密码登录正常；站内通知仍按角色、订阅、提及和启停状态投递。使用隔离测试数据库和 4184 预览，保留未交付的工作区 UI 改动。当前不部署 main、4180 或云端。
