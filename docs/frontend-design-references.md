# 前端设计参考

本文档于 2026-09-16 从 `jt_case_platform/docs/frontend-design-references.md` 迁入，保留已确认的 JT 视觉规则，并将案件业务及实现路径适配为 JT Idea Notes / Fider。本文是后续修改的设计约定，不表示当前页面已完成这些调整。

## 当前设计基准

- 沿用来源项目于 2026-09-08 确认的「清晰蓝」方向：蓝色强调色（浅色主题 `#285ada`）、中性浅灰导航背景、白色工作区和无衬线界面文字；使用本项目已确定的名称与标识，不以酒红和金色作为主配色。
- 以本项目现有想法列表、记录详情、记录入口和状态操作为结构基准，保持清晰的业务层级；如调整侧栏，可参考 shadcn/ui Sidebar 的分组、折叠和底部账户区，不为套用范例额外引入导航层级。
- 颜色统一通过全局主题变量调整，深色模式同步适配；成功、警告和错误保留各自的语义颜色，不随主色替换。
- 记录优先。设计调整服务于快速填写、查找和理解进展，不增加强制结论、审批或额外表单步骤。

## 组件外观与交互

沿用来源项目于 2026-09-08 确认的白色胶囊工具栏方向。依据 2026-09-17 已确认范围，全站采用案件平台的左侧全局导航、顶部路径栏和白色工作区；首页保留紧凑列表、顶部新建入口和右侧详情抽屉；全站控件尺寸和交互效果按案件平台实际实现映射，保留业务流程。外壳尺寸与交互见 [外壳方案](./jt-workspace-shell-plan.md)，既有控件值与来源见 [控件实施方案](./jt-ui-refresh-plan.md)。

- 白色和中性浅灰区分层次，减少装饰性边框与渐变；正文和辅助文字保持可读对比度。
- 按钮、工具栏和分段切换采用胶囊圆角，卡片与弹窗采用适度圆角；按已确认布局收紧间距，列表使用单一表面与细分隔线。
- 普通悬停与按下使用中性灰色层次；蓝色集中用于主操作与选中背景，输入框聚焦使用下述样式约定。
- 操作图标统一灰色细线；内容图片及具有独立语义的彩色文件图标保留。
- 阴影主要用于菜单、弹窗等浮层；小控件使用轻量阴影，不通过重阴影堆叠层次。
- 动效只平滑颜色、边框与阴影；避免悬停位移和装饰性缩放，保留必要的进度与加载反馈。
- 浅色、深色模式共用主题变量与状态规则，键盘焦点、禁用及错误状态须清晰可辨。

### 输入框聚焦样式

沿用来源项目于 2026-09-09 确认的规则：后续新增或调整组件时，不使用粗蓝色外框、双层焦点框或外扩蓝色光圈。

- 文本输入框聚焦时保持默认浅色边框，与未聚焦时一致；不加深边框、不叠加装饰性 `outline` 或焦点阴影，保留原有尺寸和圆角。
- 保留文本插入光标、键盘操作和错误提示；错误状态沿用原有错误色。按钮、链接、选择框等非文本输入控件仍保留可辨的键盘焦点提示。
- 不通过全局清除焦点样式来实现这一规则；修改后实际检查 Tab、Shift+Tab、输入和提交，确保焦点位置可辨。
- 本项目待调整位置参考：[输入框样式](../public/components/common/form/Input.scss)、[多行输入样式](../public/components/common/form/TextArea.scss) 和 [全局焦点样式](../public/assets/styles/utility/outline.scss)。这些文件目前属于 Fider 原版实现，不视为已经符合迁入规则。

### 浅蓝胶囊选中态

沿用来源项目于 2026-09-09 确认的导航选中效果，后续紧凑导航项需要类似效果时，可按场景复用。

| 要素 | 约定 |
| --- | --- |
| 背景 | 浅蓝色；浅色主题目标为 `#e8efff` |
| 圆角 | 完整胶囊轮廓，保留控件尺寸 |
| 阴影 | 轻微浮起的层次；浅色主题参考 `0 1px 3px rgb(0 0 0 / 5%)` |
| 文字 | 中性深色、字重 `500`，由背景表达选中 |
| 图标 | 保持中性色或继承文字颜色，独立状态沿用各自语义 |

- 轻微浮起的效果来自阴影，无需额外叠加白色底层；保留组件原有尺寸和间距。
- 选中态表示当前位置，与鼠标悬停、键盘聚焦分别处理；导航项保留可辨的键盘焦点提示。
- 深色模式使用同一套变量名称，由主题调整颜色与阴影。
- 本项目导航实现参考：[Header 组件](../public/components/Header.tsx) 和 [Header 样式](../public/components/Header.scss)；仅在当前改动需要时应用。

## 在 Fider 中落地

- 前端位于 `public/`，沿用 React、TypeScript、SCSS、BEM 命名及现有工具类，不新增一套 Next.js 或 Tailwind 实现。
- 主题入口：[浅色变量](../public/assets/styles/variables/_colors.scss)、[深色变量](../public/assets/styles/variables/_dark-colors.scss) 和 [主题生成逻辑](../public/assets/styles/utility/_theme.scss)。
- 本项目使用 `--colors-primary-base`、`--colors-primary-dark`、`--colors-gray-*` 等变量；先映射到现有主题体系，再按实际需要补充缺少的语义变量。
- 来源项目的 `--brand-soft`、`--control-hover`、`--control-active`、`--shadow-floating`、`--shadow-control`、`--radius-pill`、`--ink-*` 和 `--line` 是设计语义参考，不假定这些变量已存在于本项目；不要直接粘贴未定义的变量或一次性复制整套主题。
- 新增与调整文案沿用 `locale/` 的翻译机制。设计规则不要求替换已有登录、权限、存储或编辑器实现。

## 使用顺序

1. 先检查本项目现有页面、组件、样式、导航和业务层级，保持界面结构连续。
2. 以案件平台的实际组件与最新约定为准逐项映射；上述网站仅在没有对应来源时作补充。
3. 将参考方案适配到本项目颜色、字体、间距、信息密度、响应式和可访问性规则，不直接套用整套主题。
4. 没有一对一组件时采用相同语义 token 和交互规则，并在验证记录中标明适配。

## 边界

- 外部网站只提供设计参考，不替代本项目现有前端和业务需求。
- 不因范例使用某个框架或组件库就新增依赖；优先复用项目现有组件、CSS 和框架能力。
- 不照搬来源代码、图片或品牌资产；实际使用前按当前页面需要确认许可、响应式和可访问性。
- 动效保持克制，只在状态变化或操作反馈确有需要时参考 Transitions。
- 页面采用白色、冷灰工作面和清晰业务层级，避免玻璃拟态、发光、复杂动画和营销式 AI 界面。
