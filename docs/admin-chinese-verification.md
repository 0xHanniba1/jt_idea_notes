# 站点设置中文化验收

关联：[Issue #5](https://github.com/0xHanniba1/jt_idea_notes/issues/5)。

## 范围与翻译约定

- 后台导航、通用设置、访问权限、成员、标签、邀请、登录方式、OAuth 配置及测试窗口、高级设置、Webhook、数据导出，以及有条件显示的内容审核、订阅与账单、删除站点页面均接入原有 Lingui 翻译机制。
- 管理页面与管理 API 继承站点语言；服务端页面标题、字段校验及操作提示提供简体中文，保留英文与其他语言的英文回退。新增 402 个客户端消息键、91 个服务端消息键。
- `Invitation` 在通用设置中译为“输入提示文字”，区别于“邀请用户”；说明当前记录弹窗不使用该旧设置。首页欢迎标题为空时实际回退到站点名称，不再写“隐藏”。新记录正文模板允许编辑。
- `Privacy` 按功能译为“访问权限”；私有标签仅管理员和协作者可见。`Verify` 在内容审核中表示“设为受信任”，不表示身份验证。角色调整使用“设为”，避免将降级描述成升级。
- OAuth 的受信任来源、角色过滤及管理员/协作者例外按实际代码说明；Webhook 的地址、请求体、请求头、函数说明分别核对。模板表达式、JSON 键、协议、示例原始值和底层诊断保留原样。
- 服务端既有字符串长度限制使用 UTF-8 字节，中文提示按“最多 N 字节”准确描述，不改变校验边界。图像大小边界允许等于最大值，中文说明同步为“不超过”。
- 修正 Webhook 模板帮助中既有的加载/失败状态文案倒置；状态 CSS 类使用固定英文值，不随翻译改变。
- 无数据库迁移，不变更权限、数据导出格式、登录策略、实际邮件发送或 Webhook 发送逻辑。

## 验证

- 前端 ESLint：0 错误，保留原有 `public/services/fider.ts` 的 2 个非空断言警告。
- Jest：20 个测试套件、182 项测试通过。
- Lingui 提取/编译、SSR 与生产前端构建通过；前端构建保留既有 CSS 顺序/资源体积警告。
- `go test ./app/actions ./app/handlers/... ./app/pkg/validate ./app/pkg/web ./app/middlewares ./app/cmd ./app/services/webhook -race -short` 通过（使用独立 `test-env`）。
- 新增定向测试验证中英文后台校验、中文 UTF-8 长度边界，以及 Webhook 地址安全校验在本地化前后保持一致。
- 独立译文复核：425 个新增或复用的客户端词条，插值与富文本标签均匹配英文源；服务端双语键一致。
- Chrome 在独立 4181 环境检查 9 个常用后台页面、中文服务端标题、通用设置/标签/OAuth/Webhook 表单错误、模板说明与预览错误、staff/admin API 中文校验、390px 布局及深色主题。
- 对未启用的审核、计费和删除站点分支使用浏览器合成数据渲染：审核非空列表与 4 种模拟操作结果、免费/Pro/旧套餐、中英切换、删除弹窗与日期/子域名插值均通过，未发送真实写入或外部请求。未被页面使用的卡片组件另以 React + Lingui 验证 2 项测试通过。
- 实际保存站点语言为英语后，页面、标题、错误均切换为英语；测试结束已恢复原开发站点设置。4180 不用于这些写入测试。

## 验证边界

外部 OAuth 提供方、Stripe 付款、站点真实删除与向外发送 Webhook/邀请不属于本次中文化验收，不触发这些操作。技术响应和用户自填数据不强制翻译。

上游既有的邮箱登录校验在没有 OAuth 服务时，对启用和关闭均会报错；本次保留业务逻辑，仅翻译提示。通用设置旧输入提示字段仍可保存，但当前记录弹窗不会使用它，界面已明确说明。

证据保存在本机 `tmp/admin-zh/`（不提交登录状态、截图或环境密钥）。
