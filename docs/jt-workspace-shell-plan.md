## 实现

1. 将 Header 转为统一展示外壳，接受 children、title、section；保留原菜单功能。
2. 页面通过 Header 包住原内容；覆盖 Fider 的按视口计算宽度，改为占满剩余工作区。
3. 侧栏折叠状态在本地保存，支持传统整页路由往返；存储不可用时退化为本页状态。
4. 窄屏导航复用现有 Modal 栈，使用原有遮罩、Escape、焦点圈定与恢复。窄屏断点沿用想法簿现有680px（案件平台为480px），避免挤压原有表单；触控目标至少44px。
5. 原语言机制继续使用；不更改身份、权限、API、数据库或登录方式。
